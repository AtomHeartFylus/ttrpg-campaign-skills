# <Campaign> — <job> overlay

**Run `ttrpg-<base skill>` first.** It owns the procedure, the structure and the checks.
This note adds only what is specific to *<Campaign name>* and cannot be expressed as a slot in
`campaign-profile.md`.

## Campaign-specific constraints

<Only irreducible things. Examples of legitimate overlay content:>

- **House aesthetics** of a produced text (a verse form, a house voice, a forbidden vocabulary).
- **Behavioural patterns of this table** that feed the red team (P9) — the moves this group
  actually makes, named, with the standing question they impose on prep.
- **Casting rules** for figures in this setting (cultural proximity, which real figures are
  admissible and how they must be handled).
- **A test this campaign applies** to any new element before it enters play.

## What belongs in the profile instead

If you are about to write here the name of a mechanic, a folder, a cadence, a guide NPC or a
convention — stop: that is a **profile slot** (`campaign-profile.md`). Overlays that restate
profile facts drift out of sync with them.

## Size check

Past one page, this overlay is a symptom: the base skill is missing a slot. Fix the base skill.
