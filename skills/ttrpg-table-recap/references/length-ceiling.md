# Recap length ceiling — Phase 2 detail

> **Only needed while writing or verifying a recap.** The entrypoint keeps the operational rule;
> this reference carries the explanation and the one-way procedure.

`D.recap` declares the recap's form, audience and reading-time ceiling. The ceiling is a table
value, not a constant belonging to this skill: a thirty-second cold open and a sung chronicle are
both legitimate. If the slot declares no ceiling, use only the `default:` the slot itself declares
(three to five minutes), say that you used it, and offer to record the table's real ceiling in
`D.recap`. Never default the form: no form means no recap.

## Measurable proxy

An agent cannot literally read aloud and time itself. Count the recap's words — or, if `D.recap`
gives a form-native unit instead of minutes (a fixed number of strophes or one page), count that
unit — and compare it to the declared ceiling. **Do not invent a reading pace to turn a word count
into minutes.** A number stated on this skill's authority would be a hardcoded constant with a
friendlier name, exactly what the four-state rule forbids.

If `D.recap` carries a pace in the table's own answer (for example, "ceiling three minutes, read
at a brisk clip"), report the raw count, the recorded pace and the resulting estimate. If it has no
pace, report the raw count next to the ceiling, let the GM judge the fit by ear, and ask once whether
the table wants its actual pace added to `D.recap`. The pace belongs in that existing slot, not in
an overlay: it is a table value, not irreducible procedure or aesthetic. Once a pace is on record,
divide the count by it and report both numbers.

If the text exceeds the ceiling, cut beats; do not compress every beat into a flat summary. The
central turn and the closing image remain proportionate to the form.

**Actually reading the recap aloud, end to end, is the GM's action, not this skill's.** The run
report says whether that happened; the skill never claims that the phase performed the reading.
