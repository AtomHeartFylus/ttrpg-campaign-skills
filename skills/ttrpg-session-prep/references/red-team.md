# Derailment red team and content margin

Read this before finishing a prep document, or when running the prediction pass as a separate
step (it delegates well: it needs the scene plan, the player dossiers and the past logs, nothing
else).

---

## The red team pass (P9)

1. **Input:** the scene plan just written + the playstyle sections of every expected player's
   dossier + past session logs. Real derailments already observed are the best predictor, so this
   pass sharpens every session the campaign runs.
2. **Output:** the **3–5 most likely derailing choices** of *this* table for *this* session, each
   with its **response pressure** — never a wall, always a consequence. The enemies *pursue*; the
   door *stays the only exit*; the soul *calls them by name as they leave*.
3. Fold each response into the `If they derail:` line of the affected scene. A scene without that
   line is a scene that only works if the players cooperate.

### The question that catches the most

*"What if they solve this from an angle I did not plan — using an NPC, a rule, or an agreement as
leverage?"*

A group that habitually plays laterally is not derailing; that is its style, and it deserves
coherent consequences rather than walls. Record your table's recurring patterns in the campaign
overlay, named, so this question gets concrete instead of generic: a named pattern predicts, a
generic warning does not.

### What a good response pressure looks like

| Bad (a wall) | Good (a consequence) |
|---|---|
| "they cannot leave the room" | "leaving costs them the thing they came for, and it is watching" |
| "the NPC refuses" | "the NPC agrees, and charges a price the table will feel next session" |
| "the fight continues" | "the fight follows them into the next scene, worse lit" |

The test: after the response, are the players still making choices? A wall ends the scene; a
consequence moves it somewhere you did not plan but can still run.

## Content margin (P8)

Prepare more than one session can cover:

- **1–2 optional scenes** beyond the main path, tagged `(optional)` in the title. They fall first
  when time runs short, and they cover the gap if the group burns through the core faster than
  expected.
- The **main path alone must already make a satisfying session**. Optional scenes are margin, not
  a crutch for a thin plan.
- If an optional scene carries a hook and gets skipped, write into `If they derail:` how the seed
  can be recovered later — or **declare it lost**. An unrecorded skipped hook is the most common
  way a campaign quietly loses a thread.

Where the session length is declared (`B.length`), size the main path against it and mark the
scene you would cut first before the evening starts, not during it. If `B.length` is empty, prep
the main path only and ask for the hard stop once.

**`D.shape` = `one-shot`:** the margin still applies, but a skipped hook cannot "come back later" —
there is no later. Declare it lost, or fold it into the ending. Never write a recovery plan for a
session that will not happen.
