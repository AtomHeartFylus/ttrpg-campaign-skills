# Reduced prep, in full

Needed one way only — when the GM explicitly asks for a shorter prep this time. Never on this
skill's own initiative, and never because a slot is empty: an empty slot degrades exactly as
Phase 0 states elsewhere in `SKILL.md`; it is never a trigger for a smaller prep. This is a
**per-run accommodation, not a default** — no number here belongs to this skill's own authority,
and `E.overrides` does not change: an override is a permanent working agreement the table chose at
setup or later, this is one session's time budget.

## The irreducible core

**The Phase 0 gates are not part of what this shortens.** `B.distance`, `B.safety` and `D.shape`
ask or stop exactly as they do in a full prep — same stop-and-ask shape, same conditions, nobody
asked less. A reduced prep with an eroded safety gate is not a smaller version of this skill; it is
the consent-and-refusal failure the package treats as unassailable everywhere else, wearing a
budget excuse.

Produce only:

- the **trigger box**, opening every scene, before the read-aloud;
- the **opening read-aloud** for the first scene (inlined, only what the senses perceive);
- the **dramatic compass** per scene (question / what earns a reward here / non-combat exit);
- the **`If they derail:` line** per scene;
- **distributed spotlight** (P7) — the per-scene `Spotlight → <PC>:` checkbox, read from
  `ttrpg-table-dossier`'s ledger as always, never recomputed.

## What is deferred, and declared

Say so in the run report, by name, every time — never silently:

- **Content margin** (P8) — no optional scenes beyond the main path this session.
- **A written white-space scene** (P6) — if the table still wants the conversation beat, it
  happens unscripted at the table; nothing here plans it.
- **The recurring guide's beat** (`D.guide`) — skipped this session, not retired: say so, so it is
  not silently forgotten for next time either.
- **Full red-team prediction** (P9) — no 3–5 derailment list; the `If they derail:` line per scene
  is the only safety net for going off the planned path.

## Verify

- Every element of the irreducible core is present for every scene that made the cut.
- The run report names each deferred element **by the list above**, not a vague "shortened this
  week" — a GM re-reading the report next month should be able to tell what was skipped without
  re-reading the prep itself.
- Nothing here reads as a permanent change: the next prep this skill writes, unless asked again,
  is the full one.
